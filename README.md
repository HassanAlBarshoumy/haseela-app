# حصيلة — مدرب الذاكرة الشامل

تطبيق ويندوز تعليمي لحفظ المعلومات بتقنية التكرار المتباعد، مصمم أصلاً ليعمل بسلاسة كاملة مع قارئات الشاشة.

هذا المستودع مخصص للتنزيلات الرسمية فقط. تطوير البرنامج يجري في مستودع خاص.

## التنزيل

1. افتح صفحة Releases في هذه الصفحة.
2. نزّل haseela-setup.exe للتثبيت الكامل مع الاختصارات.
3. أو نزّل النسخة المحمولة المضغوطة إن أردت التشغيل دون تثبيت.

## ملاحظات

1. البرنامج مجاني للاستخدام الشخصي والتعليمي، وجميع الحقوق محفوظة لمالكه.
2. تفاصيل الرخصة والمكونات مفتوحة المصدر داخل البرنامج من قائمة مساعدة ثم حول.
